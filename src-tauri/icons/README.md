# Icons

Thư mục này sẽ chứa icon app sau khi chạy (cần Rust + Tauri CLI):

```powershell
& "C:\Program Files\nodejs\npx.cmd" tauri icon logo.png
```

Lệnh trên tự sinh `32x32.png`, `128x128.png`, `128x128@2x.png`,
`icon.icns`, `icon.ico` đúng chuẩn `tauri.conf.json`.
Dùng ảnh vuông PNG ≥ 1024×1024 để icon đẹp.
